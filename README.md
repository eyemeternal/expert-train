# Moziserve Website Redesign

This workspace contains the project for reconstructing the Moziserve website with responsive, accessible layouts while retaining its existing logo, colours, and verified business information.

Start with the [project documentation](docs/README.md) and [delivery milestones](docs/moziserve/delivery-plan.md). The [source audit](docs/moziserve/source-audit.md) records the evidence available for the [aesthetics review](docs/moziserve/aesthetics-review.md).

The `rea/` and `everything-claude-code/` directories are independent local reference repositories. The replacement website is planned for `moziserve/` after the source capture and aesthetics review.
