# Redesign Brief

## Objective

Give the existing website a modern facelift through typography, spacing, composition, imagery, and navigation. Preserve verified business identity and meaning. Improve clarity and the path to contacting the business.

This is a proposed direction. The existing design and business sector have not been observed.

## Proposed visual direction

Use a restrained editorial layout: generous whitespace, strong headings, readable body copy, a consistent spacing scale, and deliberate image placement. Retain the existing website colours. Extract exact values from source styles and computed styles, record their current roles, and reuse them as design tokens. Do not substitute a new neutral palette or accent. Preserve the existing logo. Colour values remain unknown until source evidence is available.

Use a fluid content width, a four-column mobile grid, and a twelve-column desktop grid. Prefer CSS grid and intrinsic layout over fixed dimensions. Keep body copy at least 16px, limit paragraph width, and use clear heading levels. Use subtle transitions and respect reduced-motion preferences.

Avoid generic filler cards, decorative dashboards, invented statistics, and fabricated testimonials. Use authentic business imagery when its provenance is known. Do not represent stock photography as completed client work.

Before rebuilding components, present the source screenshots, palette inventory, and proposed component treatments for the user to inspect. Modernize composition, spacing, typography, and interaction while preserving the verified colour identity. See the [aesthetics review](aesthetics-review.md).

## Proposed visitor journey

1. Header: verified identity, concise navigation, and a clear contact action.
2. Introduction: explain the verified offer, audience, and location in plain language.
3. Services: summarize only evidenced services with descriptive links.
4. About: communicate substantiated experience and credentials.
5. Work or proof: include only when authentic examples are available.
6. Contact: show verified channels and explain the next step.
7. Footer: verified contact links and applicable existing policy pages.

These are candidate sections, not observed source pages. Route count and final content depend on the audit. A contact form is optional until an actual delivery destination and consent requirements are established.

## Content and accessibility

Use concise South African English. No emojis or em dashes in any authored text. Keep telephone numbers, addresses, company claims, and service names accurate. Use semantic landmarks, keyboard navigation, visible focus, descriptive links, labelled controls, and appropriate image alternatives. Target WCAG 2.2 AA contrast and interaction behaviour, with manual checks before claiming conformance.
